# NevaVision

Независимый прототип внешнего оверлея для **Русской Рыбалки 4** под Windows 11 x64. Рабочее название можно заменить перед публикацией.

Прототип повторяет нужное поведение NEREST на уровне пользовательского интерфейса:

- показывает название рыбы, вес, дистанцию и слот удочки;
- подаёт однократный звуковой сигнал при появлении новой записи рыбы;
- содержит помощник поклёвки;
- имеет демонстрационный режим без запущенной игры.

Приложение читает память процесса только через `OpenProcess(PROCESS_VM_READ)` и `ReadProcessMemory`. В исходниках нет `WriteProcessMemory`, DLL-инъекции, автоматической подсечки или изменения игровых настроек.

## Текущее состояние

В `Core/Rf4Signature.cs` зафиксированы цепочки указателей, которые были восстановлены по поведению NEREST для RF4 `4.0.25034`. В них входят объект рыбы, позиция игрока для расчёта дистанции, вес, слот, имя и флаг редкости. Это экспериментальная сигнатура: после запуска на конкретном клиенте нужно проверить реальные значения в игре. Если RF4 обновится, меняется только этот файл и при необходимости таблица `Core/FishNames.json`.

Первый запуск начинается в демо-режиме. Кнопка **Подключиться к RF4** переводит приложение к чтению процесса, если запущен `rf4_x64.exe` и доступ к `GameAssembly.dll` разрешён.

## Запуск загруженного архива

После скачивания нажмите правой кнопкой по ZIP-файлу, откройте **Свойства** и при наличии установите флажок **Разблокировать**, затем распакуйте архив полностью. Запускайте `NevaVision.exe` из распакованной папки рядом с каталогом `Core`.

Если запуск завершился ошибкой, приложение показывает её на экране и сохраняет отчёт в `%LOCALAPPDATA%\\NevaVision\\NevaVision-error.log`.

## Сборка на Windows 11

Установите .NET 8 SDK и выполните из каталога проекта:

```powershell
dotnet publish .\src\NevaVision\NevaVision.csproj `
  -c Release -r win-x64 --self-contained true `
  /p:PublishSingleFile=true /p:IncludeNativeLibrariesForSelfExtract=true
```

Готовый файл будет в `src\NevaVision\bin\Release\net8.0-windows\win-x64\publish\NevaVision.exe`.

В `.github/workflows/windows.yml` добавлена сборка тем же способом на GitHub Actions, если локально нет SDK.

## Дальнейшая проверка

Для подключения к живому клиенту нужны один запуск RF4, скриншот/лог о результате подключения и один момент с видимой рыбой. По этим данным можно уточнить цепочку дистанции и точное состояние поклёвки, не добавляя запись в процесс.
